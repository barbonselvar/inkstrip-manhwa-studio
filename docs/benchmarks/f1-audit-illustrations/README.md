# Original F1 audit illustrations

The procedural drawings in `scripts/ai-studio-profile.mjs` were created for this
repository. The fixture drawings are dedicated under CC0-1.0. No third-party
manga panels, character designs, fonts, datasets or reference images are bundled.
The `*-before.png` files are the original drawings; `*-after.png` files are actual
Swin2SR outputs, generated by the pinned, verified ONNX graph, not mocked results.

Categories cover monochrome manga-style hatching, colored illustrated artwork,
fine line art, a stylized character portrait and a simple architectural background.
They are deliberately small, synthetic technical fixtures (64×64), not held-out
commercial manhwa pages. They validate inference, alpha, deterministic warm reuse
and output dimensions. They do not establish identity, anatomy or aesthetic quality.
No subjective scores are assigned. Human review of representative rights-cleared
production artwork remains required for broader model quality qualification.

Reproduce after building: `INKSTRIP_QA_MODEL_CACHE=/path/to/verified/model.onnx
npm run bench:ai-studio -- http://127.0.0.1:8081`. The cache is optional and checked
against the pinned SHA-256; it supplies model weights, never generated pixels.
