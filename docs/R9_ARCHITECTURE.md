# R9 architecture — precision vector editing in Raster Studio

R9 moves the remaining precision-vector workflows into Raster Studio by **reusing** the
existing Pro document model, Bézier engine, precision/snapping engine, text-on-path engine
and SVG interchange. It adds no new document kind, no new renderer and no dependency. R8
remains the only gradient/style/Smart Filter engine; PR #21 remains the owner of
Pathfinder, path ↔ selection, masks from paths and the Raster Appearance tab.

## Document model and native compatibility

- **No schema bump.** `shapeOptions` is an optional layer field accepted for schema 2 and 3
  (the shared v2+ allow-list in `validateDocument`) and is validated strictly: only on
  `rectangle` (radius ≤ 100000), `polygon`/`star` (integer sides 3–64) and `star` (inner
  0.05–0.95); unknown keys are rejected. The new `"star"` shape value is validated with the
  other shape names.
- **Older documents render unchanged.** Omitted options reproduce the pre-R9 geometry
  (sharp rectangle, hexagon). No document is migrated on open.
- **Older readers (measured against main `db78593`'s validator).** A star is rejected in
  every schema ("Invalid vector geometry"). Schema 2/3 documents with `shapeOptions` are
  rejected ("Unknown schema2 layer field") — fail-closed. Schema 1 has no field allow-list
  (pre-existing design), so a pre-R9 build opening a schema-1 document with a corner radius
  or polygon side count accepts it and draws the pre-R9 geometry (sharp rectangle,
  hexagon); the option stays in the data. This is a forward-compatibility limitation (old
  app, new file), not a change to how current documents open.
- **Guides** live in the existing `layout.guides` (already persisted). Rulers on/off and the
  unit are per-device view preferences in `localStorage` (`inkstrip-pro-rulers-v1`,
  `inkstrip-pro-ruler-unit-v1`), never document data, and guides are never exported.

## Integration rules with R8 and PR #21

- **Smart Filters (R8).** Geometry operations that combine operands must not discard an
  editable Smart Filter stack. R8 enforces this for Pathfinder and Compound; R9 applies the
  same rule to **Join** (either operand filtered → refused, document unchanged). Split
  clones the full layer, so both halves keep styles, filters, masks and links; Smooth,
  Simplify and closed-path Split are in-place edits of one layer, like anchor editing.
- **Gradients (R8).** R9 adds no gradient tool or paint; R8's Gradient Fill stays the only
  gradient tool in Raster (`RASTER_TOOL_IDS` keeps `gradient-fill`).
- **Inspector tabs.** Paths (PR #21) is Raster-only; Pathfinder and Artboards stay
  Vector-only; Appearance (PR #21), Precision and Typography (R9) are shared. Raster
  therefore shows 13 tabs; a bar with 13+ tabs auto-fills 4rem columns (four at the default
  300 px panel), so it keeps the pre-R9 height and the panel content its space.
- **Pathfinder / masks from paths (PR #21)** accept R9 stars and rounded rectangles through
  the existing `parseSvgPath(shapePath(l))` conversion; no new code path.

## Algorithms

- **Split** at an anchor opens a closed contour (one layer) or cuts an open single-contour
  path into two layers (the second is inserted above the first). Handles on the cut are
  removed so the curve does not change.
- **Join** maps the second path into the first layer's local space (inverse of the first
  transform × second transform), picks the nearest endpoint pair of the four orientations,
  merges coincident endpoints (≤ 0.5 px) or bridges with a straight segment. Refused for
  closed/compound paths, perspective/warp, different groups, Smart Filters, > 1000 anchors.
- **Smooth** sets Catmull-Rom-style handles parallel to the neighbour chord, one third of
  each adjacent segment.
- **Simplify** greedily removes the anchor whose two adjacent segments are best replaced by
  one cubic (Schneider least-squares handle lengths with fixed end tangents), accepting
  only fits whose maximum residual against the **original** segment samples is within the
  tolerance, so error never accumulates. Candidates are cached and only the two
  neighbours of a removed anchor are re-fitted: the 900-anchor case went from 44.1 s to
  84 ms on the validation machine (see the test report). Open-path endpoints are kept; straight fits stay lines.
- **Rulers** map document coordinates to screen through the same fit, zoom, pan and
  quarter-turn view rotation as the canvas; free rotation shows a note instead of a wrong
  scale.

## Limits

1000 anchors per path (existing), simplify tolerance 0–100 px, 3–64 polygon/star points,
existing document/layer/pixel budgets unchanged.
