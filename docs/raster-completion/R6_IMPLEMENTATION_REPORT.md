## Persistent editable adjustments

Raster Studio → Properties → **New color adjustment** creates an editable operation above the selected complete clipping stack, or inside a selected group. **Edit adjustment settings** reopens an existing record. All eleven color families use the already tested R6 pixel engine: Brightness/Contrast, channel Levels, channel cubic Curves, HSL, tonal Balance, linear Exposure/Gamma, Vibrance/Saturation, channel-mixed B&W, Invert, Posterize and Threshold. Settings, optional preset name, layer identity/order/visibility/opacity/blend and masks remain editable after native save, reload and recovery.

The panel reuses the current sliders, numeric inputs, channel controls, curves graph/control points, real histogram and factory/custom presets. Its preview is the **actual complete proposed composite**. Before/after compares the committed document. The native-resolution histogram samples the backdrop immediately before this layer in its own stack. Draft parameter changes add neither assets nor history nor autosave metadata. Cancel restores the exact accepted settings, including while work is queued. Apply checks current document identity and the displayed parameter key, then commits one existing history action. An unchanged Apply is a no-op. Document/layer changes and unmount invalidate the draft; worker generations discard stale results.

Original raster pixels, paint strokes and vectors are never rewritten by these adjustment layers. Ordinary layer controls provide visibility, opacity, reorder, duplicate with a new ID, delete, masks and Undo/Redo. The tests include painting with R3 after adjustments and transforming the underlying raster with R5, with exact Undo.

## Existing pixel workflow retained

**Color & Filters** still opens the original source-layer pixel lab for one visible unlocked raster/paint layer. Its preview is before the target's masks, clipping, opacity and effects. It retains real spatial/noise filters, native source preview, captured selections, presets and Apply/Cancel/Reset. Apply produces an ordinary PNG asset while retaining the editable hidden original; this established pixel workflow is distinct from the metadata-only adjustment-layer workflow. Spatial filters have not been mislabeled as persistent adjustment layers.

## Algorithms and color model

All documents still store 8-bit encoded-sRGB straight RGBA. Canvas2D/OffscreenCanvas compositing follows the existing browser pipeline. No ICC-managed editing, wide gamut, 16-bit document precision or GPU filter backend is claimed. Intermediate Gaussian sums use Float32 and scalar/LUT calculations use JavaScript floating point; lookup mappings keep floating point until pixel assignment; reused legacy operations retain their established 8-bit stage boundaries before PNG encoding. Multiple accepted destructive operations can accumulate quantization; use the retained original to restart.

| Operation                      | Actual algorithm                                                                                                                                                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brightness / contrast          | Reuse legacy additive brightness and exponential contrast around encoded midpoint 127.5; stable source, alpha untouched                                                                                                         |
| Levels                         | Clamp input black/white, exponent `1/gamma`, map to ordered output endpoints; composite RGB first, then independent R/G/B                                                                                                       |
| Curves                         | 2–16 strictly ordered integer input knots per RGB/R/G/B channel; shape-preserving cubic Hermite with Fritsch–Carlson tangent limiting; no local segment overshoot; composite then per-channel LUT with fractional interpolation |
| Histogram                      | All native source pixels, visible samples weighted by alpha; independent R/G/B bins; RGB display is Rec.709-weighted encoded luma                                                                                               |
| HSL                            | Conventional encoded-RGB ↔ HSL; wrapped hue, relative saturation and lightness toward black/white; optional six hue ranges with full effect within 30°, smoothstep fade to zero at 60°, with saturation gating to protect grays |
| Color balance                  | Reuse quadratic luma-range weights `(1-L)^2`, `2L(1-L)`, `L^2`; optional encoded-luma preservation with chroma shrinking into gamut                                                                                             |
| Exposure / gamma               | Decode sRGB transfer, multiply linear light by `2^stops`, clamp, re-encode, apply encoded `1/gamma`; distinct from unchanged legacy encoded-exposure setting                                                                    |
| Vibrance / saturation          | Reuse existing chroma-distance vibrance around Rec.709 encoded luma; positive gain scales by `1-chroma`, protecting saturated pixels; existing global saturation follows                                                        |
| Black and white                | Editable additive R/G/B percentage mix, default 21.26/71.52/7.22; encoded luma, not physical luminance                                                                                                                          |
| Invert / threshold / posterize | Visible RGB complement; inclusive luma cutoff; exact requested 2–256 channel levels. Threshold/posterize reuse existing implementations                                                                                         |
| Gaussian                       | Genuine normalized separable Gaussian kernel, sigma 0.1–32 and support `ceil(3*sigma)`; clamp borders                                                                                                                           |
| Box                            | Existing separable running-sum alpha-weighted box, radius 1–32; clamp borders                                                                                                                                                   |
| Motion blur                    | 1–63 symmetric line samples at the chosen angle, nearest integer positions; alpha-weighted RGB and clamped borders; documented discrete line, not a second Gaussian                                                             |
| Sharpen                        | Four-neighbor Laplacian high-boost with alpha-aware neighbor fallback                                                                                                                                                           |
| Unsharp mask                   | Source minus Gaussian, adjustable gain and difference threshold                                                                                                                                                                 |
| Add noise                      | Deterministic seeded uniform noise, monochrome or independent channel draws                                                                                                                                                     |
| Noise reduction                | Reuse existing 3×3 alpha-weighted edge-aware denoise, excludes large color differences                                                                                                                                          |
| Median                         | Per-channel alpha-weighted median over radius 1–3 neighborhood, ignores invisible samples                                                                                                                                       |
| High pass                      | Source minus Gaussian plus encoded middle gray 128                                                                                                                                                                              |
| Edge detection                 | Sobel gradient magnitude of encoded luma, normalized by 4; black means no edge                                                                                                                                                  |

Spatial operations preserve source alpha instead of expanding silhouettes. Gaussian/box/motion normalize premultiplied color and coverage so invisible RGB cannot produce colored fringes. Median weights by alpha; sharpen/Sobel mix weakly covered neighbors toward the current source color. Fully transparent RGB remains unchanged in the pixel engine; the existing Canvas/PNG boundary can canonicalize invisible color to zero. Captured selection crossfades the result once against the stable source. Filtering uses surrounding source pixels even outside the selected area; the selection limits where output is written.

## Compositing, history and document safety

An unclipped adjustment transforms the visible backdrop below its position in the same isolated group, including that group's accumulated child composite. It cannot serve as a clipping base. A clipped adjustment transforms only its base stack. Upper artwork and outside-group siblings are unaffected. Group mask/opacity/blend follow child compositing. Adjustment coverage uses the existing transformed layer plane, mask placement/linkage, density/feather and clipping alpha. Existing supported RGB blend math and layer opacity interpolate filtered RGB against the backdrop; backdrop alpha remains unchanged. Hidden layers skip processing. Locked adjustments/locked destination groups reject editing. Locked underlying artwork may be viewed through an adjustment without modifying it.

Each operation quantizes through the existing8-bit engine, so multiple stacked adjustments introduce the established stage quantization. Native editable settings allow recalculation from original sources rather than cumulative slider degradation. Spatial layer effects on an adjustment plane are not a newly supported feature; group/artwork effects keep their existing behavior.

Persistent preview uses an isolated renderer with decoded-source reuse, 70ms parameter debounce and cancellation checkpoints between tiles. Histogram work uses a separate short-lived renderer. No competing history implementation was introduced. R3 stroke finalization and R5 transform transactions retain their existing guards.

**Confirmed defect fixed:** an older queued Undo autosave could acknowledge after a rapid Redo returned to a formerly saved state, leaving the latest state unscheduled. A save is now acknowledged only when the FIFO is clear and its durable document matches the current document. Successful stale acknowledgements trigger another autosave check; pending writes also trigger the unload warning. Existing revision conflict rejection, immutable asset merging and explicit close/save are preserved. Reload tests verify actual durable records, not only a transient UI label. A blocked IndexedDB write also verifies that close waits for the durable current document before Chapter backup navigation. An apparent one-level recovery mismatch was an interrupted close in the test, reproducing the missing new brush stroke; synchronization was corrected and zero-tolerance pixel assertions retained. No color algorithm was changed to hide it.

## Native schema, migration and recovery

Actual internal document version is **2**, portable envelope **8**, adjustment record version **1**, IndexedDB `inkstrip-pro` version **4**. Envelope6 remains reserved for independent AI PR6, envelope7 remains legacy Dialogue. Full schema/validation details are in [R6_NATIVE_SCHEMA.md](R6_NATIVE_SCHEMA.md).

Existing documents1 and envelopes1–5/7 remain readable and re-export in their original feature envelope. Creating the first advanced adjustment performs an immutable opt-in1→2 metadata migration in the same history transaction. It preserves every legacy layer, source ID/byte and setting. Undo can restore1. Schema2 always exports8, even after deleting the final advanced adjustment; it never silently down-converts. Canonical key ordering and unchanged layer-array ordering make new native output deterministic.

Typed `Layer.adjustmentLayer` contains `{version:1, operation, preset?:{name}}`, with strict operation/range/channel/curve validation. New root/layer/mask/record keys, dangerous JSON keys, mismatched schema/envelope, unsupported types/versions, malformed assets, excessive nesting/count/bytes and processing resources reject gracefully before unsafe decode/processing. No serialized code is executed. Existing image header/decode safety remains in the import path.

Older applications reject portable8 and internal2, including inside Chapter backups. The storage3→4 upgrade changes no stores or source/session data; it prevents an older same-origin reader reopening writable new recovery drafts. Existing versionchange/blocked handling and independent AI-draft upgrade guard remain. Chapter backup header2 is retained: its established nested native validation safely rejects unsupported internal versions in older apps. New backup restore preserves typed sessions atomically through the existing recovery journal; a fresh-browser-context test opens, renders and saves the restored session.

PNG export is pixel-exact to the visible committed composite and pre-/post-reopen output; JPEG/WebP use existing matte/quality semantics. SVG continues to reject adjustment layers explicitly, avoiding omitted operations. Standard image exports flatten their composite; native projects preserve editable sources and settings.

## Resource bounds and measured scale

Persistent operations are pointwise and use **512×512 RGBA tiles** through the existing color engine, with no spatial halos or seams. The original processColor4MP call cap remains unchanged because every tile is smaller. Destructive/spatial operations keep their original4MP/device and128M kernel-work limits. Persistent output uses the existing device/document ceiling (desktop16,777,216 pixels, max16384px per side) plus a cumulative visible-adjustment budget `min(128M, deviceArea×8)`, accounting for padded rendering. Actual output work is checked again before output allocation. Asset64/48MB, layer48, combined-source, mask/selection and history limits remain enforced. No artwork is downscaled for native export; the existing preview-only1400px viewport cap remains.

Real-worker measurements at512²,2000²,3000² and4096² use two non-neutral persistent point layers and a large mask/density. All full PNG pixel hashes and original source hashes match after native reopen. At4096², preview took2037.7ms, native input histogram5890.6ms, first PNG export10993.5ms, and reopened export5755.4ms on this shared desktop executor. Summed Chromium process-tree peak RSS was1185MiB, including generation/hash/runtime/shared-page accounting; this is a coarse measured observation, not isolated tile allocation or mobile capacity. Detailed timings and hashes are committed with test evidence.

This supports larger **point adjustments** within existing device budgets. It does not authorize full-document spatial filtering above4MP. Full composite/coverage canvases still exist; only pixel processing and histogram buffers are tiled. There is no dirty-region/intermediate-composite cache or GPU backend. Worker source-decode caching is retained. Complex large masked stacks can be slow; work caps remain conservative, and native backup remains the recovery path when a device rejects rendering.
