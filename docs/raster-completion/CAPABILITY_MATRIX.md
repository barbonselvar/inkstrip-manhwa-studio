# R1 — live Raster capability matrix

States: **IMPLEMENTED+VERIFIED** means the specifically bounded behavior has current source plus automated/native worker or browser evidence in R1; it does not imply every combination/device/artwork is proven. **PARTIAL** means working functionality with a material workflow/quality boundary. **BROKEN** means a reproduced defect, even when subsequently fixed. **MISSING** means no advertised/usable implementation was found. **DEFERRED** means intentionally separate or awaiting approved scope/infrastructure.

Evidence shorthand: U = current `npm test`; B = current real Chromium suite under `scripts/<name>-browser-check.mjs`; S = source trace in `DEPENDENCY_MAP.md`; A = R1 supplemental audit. Native formats and shared compositing are tested across representative combinations, not a Cartesian product of every setting. View-only controls legitimately have no native document mutation. Tests use synthetic/rights-cleared fixtures, not a broad artistic quality corpus.

## R1.1 safety follow-up

Chapter picker/drop/paste/batch, replacement, original recovery, backup media and stored preview consumers now share bounded signature/dimension/resource validation before decoding. Batch publication and replacements are transactionally guarded against quota, cancellation and stale media. Native versions and rendering algorithms are unchanged. Exact limits, deliberately rejected variants, boundary tests and browser results are documented in [R1_1_REPORT.md](R1_1_REPORT.md). This is input/resource hardening, not new professional editor tools or a universal decoder safety guarantee.
