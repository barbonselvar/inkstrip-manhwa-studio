# Inkstrip Manhwa Studio

A private, responsive manhwa editor: organize projects and chapters, arrange
panels, restore images with on-device AI, stitch vertical pages, and export.
Existing projects and artwork remain in this browser's IndexedDB storage.

Use Node 24 (`.nvmrc`), then `npm ci` and `npm run dev`.

Validation: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`,
and `npm run check:build`. No deployment command is included in CI.
