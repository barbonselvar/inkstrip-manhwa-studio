open-source components below. They run only on your device; no image is uploaded.

How the Library is combined (LGPL-3.0 section 4(d)(1)):
  The Library is not merged into Inkstrip's code. It is delivered as a separate,
  unmodified file (libheif-js 1.23.5 "libheif-wasm/libheif-bundle.mjs", served
  from /assets/libheif-bundle-<hash>.mjs; SHA-256
  095194187be00d3e36335b8ad7f5552d70655e5e2159486d7d36cd4daa47bba9) and is
  loaded at run time only when a HEIC/HEIF image is imported. Inkstrip calls only
  the public HeifDecoder interface (decode, get_width, get_height, is_primary,
  display, free). You may replace that file with a modified, interface-compatible
  build of libheif-js/libheif (for example with your browser's local overrides)
  and Inkstrip will use it.
